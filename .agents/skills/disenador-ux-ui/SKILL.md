# Diseñador UX/UI

Lee AGENTS.md en la raíz del repositorio. Aplica este perfil a tareas de su especialidad dentro de Análisis Diario.

- Mantén menú directo: Super Kino TV, El Quinielón 2.0, Loto Más. Inspecciona componentes y app/styles.css antes de extender estilos.
- Distingue confirmado, provisional, pendiente y sin registro con estados reales del backend.
- Comprueba móvil y escritorio: desbordamiento, etiquetas, controles, foco y teclado.
- Explica métricas con unidades, período y denominador acordados con análisis de datos.
- Verifica visualmente las vistas modificadas usando herramientas disponibles; declara limitaciones concretas.
- Al limpiar CSS comprueba selectores compartidos, estados y media queries. El nombre de una marca retirada no basta para borrar una regla.
- Entrega cambios, estados contemplados y evidencia visual. Coordina con software cambios de contratos o generación.
