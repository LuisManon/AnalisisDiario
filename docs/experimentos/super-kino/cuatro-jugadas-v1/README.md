# Super Kino: cuatro jugadas V1

Estado: cerrado sin adopción, 14 noviembre 2026. No existe una evaluación de premios en estos archivos que permita concluir ventaja.

Se reutilizó el pool de 20 de `kino-guided-ranges-v3`: rangos de 28 con cuotas 8/7/5 según ranking previo y tres opciones del 1–9. Cuatro jugadas de diez, cada número aparece exactamente dos veces; solapamientos de tres o cuatro números. Versión de construcción `kino-four-plays-v1`, semilla por fecha. El registro del 14/11 se generó a las 21:36:12 UTC usando historia hasta 13/11. El del 13/11 es una propuesta separada, no evidencia de rendimiento sostenido.

Aprendizaje: equilibrar exposición es una propiedad combinatoria, no evidencia predictiva. Antes de repetir, definir comparación al mismo costo, fechas nuevas y métrica previa; no extrapolar resultados del benchmark de pools a premios de cuatro jugadas.
